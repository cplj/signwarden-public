# Security reporting

This repository currently holds a research description and a draft field list. It does not ship a verifier, a service or executable code.

Report a problem privately to SignWarden Team at security@signwarden.com. Useful reports name the field or statement involved, explain how it could let a forged or misleading receipt pass review, and include a small synthetic example. Do not send credentials, personal information or data from systems you are not authorized to test.
