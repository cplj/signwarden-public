# SignWarden

AI 代理行動的收據與稽核紀錄：授權 → 動作 → 結果。

**狀態：研究中。** 目前沒有客戶，擬議格式與驗證器尚未經獨立驗證。

[English](README.md)

## 問題

代理的權限紀錄、工具呼叫日誌與結果紀錄可能分散在不同地方。我們正在研究：收據需要包含哪些資訊，才能讓查核者追溯行動的授權，並比對要求執行的動作與記錄的結果。

## 收據欄位：討論草案

以下是擬議欄位，尚非穩定規格或可執行的驗證介面。

| 欄位 | 預計內容 |
| --- | --- |
| `receipt_id` | 串起一次行動各筆紀錄的識別碼。 |
| `actor` | 代理身分，以及代理代表的授權方。 |
| `authorization` | 簽發者、許可範圍、限制、有效期間與權限紀錄參照。 |
| `action` | 工具名稱、要求執行的操作與輸入參照。 |
| `result` | 觀察到的結果、錯誤，或明確標示未知。 |
| `timestamps` | 授權、執行與觀察的時間及其來源。 |
| `evidence` | 佐證紀錄參照與完整性資訊。 |

這些欄位是否足夠、驗證器能核對哪些證據，仍待研究。紀錄中的主張本身，不能證明授權存在或結果確實發生。

## 開放格式、私有資料

規劃將收據格式與參考驗證器開源。託管服務與儲存資料保持私有。目前此儲存庫只有研究說明，尚未提供驗證器或託管服務。

## 給 AI 代理

用途：說明串接授權、動作與結果的擬議收據。
研究階段尚無安裝指令與可執行範例。
輸入與輸出請見上方欄位草案；目前尚無穩定的機器介面。
這份說明不構成認證，也不是部署安全的證據。
