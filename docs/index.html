SignWarden

Check permission and action regressions locally.

Run explicit synthetic cases against a trusted adapter. Inspect PASS, FAIL or UNKNOWN results and the controlled-tool evidence behind them.

Quick start

Python 3.10+; run from a local repository checkout.

python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install .
signwarden report --cases cases/sample.json --adapter examples/reference_gateway.py:Adapter --out artifacts/report

The reference adapter is expected to match all 12 public sample cases. The generated JSON and Markdown preserve inputs, checks and content fingerprints.

Evidence and limitations

Comparison research is exploratory; no independently validated comparison is currently available for publication. No advantage over handwritten tests is claimed.

A PASS applies only to the defined cases and adapter version. This is not a sandbox, production authorization gateway, security certification or deployment safety guarantee. Custom adapters execute Python code and may perform real actions.
